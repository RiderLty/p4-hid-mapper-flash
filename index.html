当前浏览器不支持 Web Serial

在线一键烧录需要 Chrome / Edge 等支持 Web Serial API 的浏览器。也可以用桌面版 esptool 手动烧录：
esptool.py --chip esp32p4 write_flash 0x0 p4-hid-mapper.bin
